# OpenBot Monitor website

Public website source for OpenBot Monitor, built with Astro, TypeScript, and CSS.

## Local development

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; Astro writes the static site to `dist/`.

The installer page uses the browser's Web Serial API. This repository contains the website source and its public visual assets; it does not include the local OpenBot bridge, ESP32 firmware, hosting credentials, or private device configuration.
